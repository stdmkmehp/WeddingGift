## 本地看页面的标准姿势（go run serve + fixtures）

- 用户问「本地只想看一眼布局如何起」：结论是没有纯静态预览（页面 bootstrap 依赖 `api/bootstrap`，静态服务器 404 会落到维护态），必须起 Go 服务。
- 已验证可用的一键流程（全部落在 `/tmp/wedding-preview`，不进仓库）：
  ```sh
  mkdir -p /tmp/wedding-preview && [ -f /tmp/wedding-preview/app.key ] || openssl rand -hex 32 > /tmp/wedding-preview/app.key
  export WEDDING_DB_PATH=/tmp/wedding-preview/local.db WEDDING_APP_KEY_PATH=/tmp/wedding-preview/app.key
  go run ./cmd/wedding migrate && go run ./cmd/wedding data import --dir testdata/fixtures
  go run ./cmd/wedding serve      # http://127.0.0.1:3000/
  ```
- 登录样例（fixtures）：张伟/20260002（G002，3 份礼品）、王芳/20260001、陈强/20260003。
- 注意：`web/` 经 `go:embed` 进二进制，改 HTML/CSS/JS 后**必须重启 serve** 才生效；`WEDDING_ALLOWED_HOSTS` 默认值不影响回环（回环地址总允许）。
- 已固化为 `ops/local_start.sh`（可执行）：一键完成「隔离目录 `${TMPDIR:-/tmp}/wedding-preview` 准备 app.key(0600)/库 → migrate → 首次自动导入 `testdata/fixtures` → 前台 serve」；参数 `--port/--reset/--no-import/--help`；`--reset` 删库重建，`--no-import` 只看登录页；含 go/openssl 检查与 lsof 端口占用预检；库已存在则跳过导入以保留登录/绑定状态。README「本地开发」段与目录说明同步。
